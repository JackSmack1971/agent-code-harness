# Agentic Coding Harness

Models propose. Deterministic infrastructure authorizes, executes, records, and proves.

This repository implements the Agentic Coding Harness described by
`docs/Unified-Implementation-Blueprint-Implementation-Closure-Edition-v1.1.md`.
Canonical machine-readable contracts live under `contracts/`; implementation
proceeds phase by phase as tracked in `.claude/references/phase-registry.md`.

## Development

```
uv sync
uv run harness doctor
uv run pytest
```
